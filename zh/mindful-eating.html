🥗 正念饮食

``` 吃饭是我们每天都会做的事情，但我们有多少时候 真正停下来，留意自己正在吃什么？ ```

``` 正念饮食是对食物、饥饿感、满足感、饮食习惯、 食物浪费以及珍惜食物多一些觉察， 而不需要让每一餐都变得复杂。 ```

🌱 什么是正念饮食？

正念饮食意味着对吃饭这件事本身多一些觉察。

与其一边分心一边习惯性地吃东西，我们有时可以 放慢一点，留意眼前的食物、味道和口感， 感受自己有多饿，以及吃完之后身体和心情有什么变化。

这并不意味着必须遵循完美的饮食方式， 或者完全避免某些食物。它只是邀请我们更加留意。

这种觉察也可以延伸到用餐之外： 食物从哪里来、我们买了多少、用了多少， 以及剩下的食物最后去了哪里。

🍽️ 为什么要更加留意食物？

食物连接着日常生活的许多方面，包括健康、文化、 家庭、享受、金钱、农业、自然资源和浪费。

当我们更加觉察自己的饮食习惯时， 可能会发现一些过去没有特别注意的行为模式。

    ```
  • 我是因为饿了才吃，还是因为食物就在眼前？
  • 我吃饭时是否经常很匆忙？
  • 我是否经常买了超过自己能够使用的食物？
  • 我是否珍惜家里已经拥有的食物？
  • 家里的剩余食物通常会怎样处理？
  • 哪些食物是我真正喜欢并且珍惜的？
    • ```

这些问题没有适用于所有人的统一答案。 重点只是先看见和觉察。

🌿 简单的正念饮食练习

正念饮食不需要特别的工具、昂贵的食物或复杂的习惯。 一些小小的改变，就可以创造更多留意食物的机会。

1. 吃之前先停一停

开始用餐之前，花一点时间看看自己准备吃什么。 短暂的停顿可以帮助我们把吃饭与自动化的行为分开。

2. 留意食物

看看食物的颜色、闻闻香味，感受它的质地和外观。 不要马上进入自动进食的状态，而是留意最初几口。

3. 可以的话，放慢一点

并不是每一餐都必须吃得很慢。 即使偶尔在两口之间放下汤匙或叉子， 也可以让我们多一点觉察。

4. 留意满足感

吃饭时留意身体的感觉， 观察自己什么时候开始感到舒适和满足。

5. 偶尔减少干扰

可以尝试偶尔在不刷手机或观看视频的情况下吃一餐。 这样可能更容易留意眼前的食物和用餐过程。

6. 珍惜食物

想一想食物来到餐桌前所涉及的人力、资源、 时间以及各种工作。

♻️ 正念饮食与食物浪费

正念饮食也可以改变我们在用餐前后看待食物的方式。

食物浪费往往在食物进入垃圾桶之前就已经开始。 我们可能买得太多、忘记冰箱里已有的食物、 准备超过需要的份量，或者让剩余食物一直没有被使用。

一点觉察可以帮助我们问一些简单的问题：

    ```
  • 家里已经有哪些食物？
  • 我大概会使用多少？
  • 剩余食物可以变成另一餐吗？
  • 可以通过不同的保存方式，让食物之后再使用吗？
  • 我是因为需要它而购买，还是只是因为它看起来很吸引人？
    • ```

重点不是因为食物而产生内疚， 而是珍惜食物，并更有意识地使用我们已经拥有的东西。

🌍 食物与环境

食物选择与环境息息相关，包括农业、土地利用、 水资源、能源、运输、包装和废弃物。

不同食物的环境影响可能有很大差异， 这取决于食物种类、生产方式、来源以及运输方式。

因此，Yangocean 不认为存在一种适合所有人的完美饮食方式。

正念饮食更鼓励我们对自己的选择保持好奇， 并在实际可行的情况下减少不必要的浪费。

如果想进一步了解日常选择的环境影响， 可以阅读 碳足迹指南 。

💚 多一点觉察

正念饮食并不要求我们拥有完美的饮食或完美的习惯。

有时候，它只是让我们放慢一点， 认真留意眼前已经拥有的东西。

当我们珍惜食物、了解自己的习惯， 并更加留意浪费时，一些小小的改变 也可以逐渐成为日常生活的一部分。
