🌳 亲近自然

留意身边的树木、植物、鸟类、昆虫、光线、雨水以及不断变化的环境。 亲近自然，可以从离家很近的地方开始。

🍃 为什么要留意身边的自然？

我们常常认为，亲近自然需要去森林、山区、公园或遥远的地方。 但其实，自然也存在于许多普通的地方。

路边的一棵树、小小的花园、屋顶上的鸟儿、正在花朵间活动的昆虫， 或者雨后出现的新叶，都可以成为让我们放慢脚步、仔细观察的机会。

当我们经常留意这些细小的变化，熟悉的环境也会变得更加有趣。

🌱 种植一些小植物

亲近自然并不一定意味着观察野外环境。 种植植物也可以让我们观察生命如何随着时间发生变化。

你不需要拥有一个大花园。一个花盆、容器或小小的种植空间， 就足以开始。

```

🌿 从小处开始

选择适合你的空间、光照和当地环境的植物。 香草以及其他容易种植的植物，可以成为简单的开始。

☀️ 观察光线

留意种植区域能够获得多少阳光，以及植物如何回应周围的环境。

💧 了解它的需要

根据具体植物及其生长环境的需要浇水， 而不是假设所有植物都需要相同的水量。

📷 记录变化

偶尔拍照或做一些记录。通过一段时间的比较， 新叶、花朵以及其他变化会更容易被发现和珍惜。

```

📓 开始一本简单的自然日志

写自然日志不需要特殊设备，也不需要具备科学知识。 一部手机和几句话的记录就可以开始。

每次观察可以记录：

  • 📅 观察日期
  • 📍 大致区域或社区
  • 🌳 你注意到的事物
  • ☀️ 天气或一天中的时间
  • 📷 一张照片
  • 🐦 看到的鸟类、昆虫或其他动物
  • 🍃 与之前观察相比有什么变化
  • 💭 个人想法或感受

随着时间推移，这些简单的观察可以成为一份属于自己的记录， 记录身边的自然世界如何变化。

🌳 认识一棵树

选择一棵你经常经过的树。不要只是从它身边走过， 偶尔停下来仔细看看。

```

🌿 叶子

留意叶子的形状、大小、颜色和质感。 是新叶、老叶，还是正在发生变化的叶子？

🌸 花朵与果实

留意花朵、种子或果实。 它们可能会吸引鸟类、昆虫和其他访客。

🪵 树皮与树干

观察树干和树枝的颜色、纹理和形状。 不同的树往往有非常独特的特征。

🐜 小小访客

仔细看看树上或树周围是否有蚂蚁、甲虫、蜘蛛、 毛毛虫以及其他小生物。

```

📷 拍下你注意到的事物

摄影可以让我们放慢脚步。 不要只是因为某样东西看起来很美就拍下来， 也可以尝试记录那些平时容易忽略的细节。

  • 🌱 一片新叶
  • 🌸 一朵刚开始开放的花
  • 🍂 一片有趣纹理的落叶
  • 🐛 正在植物上活动的昆虫
  • 🌧️ 雨后的水滴
  • 🌤️ 熟悉的树木周围不断变化的光线
  • 🌳 同一棵树在不同时间的样子
  • 🌱 你正在种植的植物

重点不是拍出完美的照片。 重点是更加仔细地观察。

👀 五分钟的自然停留

下次在户外时，可以尝试一个简单的短暂观察练习。

  1. 在安全、舒适的地方停下来。
  2. 先看看周围，而不是马上拿起手机。
  3. 留意三样你可以看到的东西。
  4. 留意周围的两种声音。
  5. 寻找一个以前从未注意过的小细节。
  6. 如果愿意，可以拍一张照片。
  7. 用一句话写下这次体验。

五分钟看起来很短，但持续观察可以逐渐改变 我们体验熟悉环境的方式。

🌦️ 观察自然的变化

大自然一直在变化，即使有些变化非常细微。

树木可能长出新叶，花朵会出现又凋谢， 鸟儿可能在不同时间出现，而雨水也能改变植物 以及周围环境的样子。

反复拍摄同一个地方或同一株植物， 可以发现那些偶尔观察时很容易错过的变化。

📝 Yangocean 自然观察

这一部分将逐渐加入来自日常环境的原创观察和照片。

```

🌳 我们身边的树木

记录普通社区环境中所见的树木、照片和观察。

🌱 种植与栽培

简单记录正在种植的植物，以及随着时间观察到的变化。

🌿 小小发现

记录日常散步时发现的有趣植物、昆虫、花朵以及其他细节。

🌧️ 雨后

观察雨水如何改变植物、树木、光线以及周围的环境。

```

新的观察将在拍摄和记录后陆续加入。

💚 观察自然，而不打扰它

亲近自然也意味着尊重自然。

  • 🌿 避免损伤植物或摘取花朵。
  • 🐦 与野生动物保持适当的距离。
  • 🦋 避免打扰鸟巢、昆虫或其他动物。
  • 🚯 将垃圾带走，或放入合适的垃圾桶。
  • 📍 避免公开敏感野生动物栖息地的精确位置。

好的自然观察应该让环境保持原来的样子， 或者在可能的情况下，让它变得更加干净。

🌱 你不需要成为植物学家

不知道每一种树、花或昆虫的名字完全没有关系。 观察可以先于辨认。

你可以从一些简单的问题开始：

  • 它看起来是什么样子？
  • 与上一次看到它相比，有什么变化？
  • 有哪些生物正在靠近或停留在它身上？
  • 下雨之后，它看起来有什么不同？
  • 是什么让这棵植物或树木对我来说有趣？

如果以后想进一步辨认物种， 这也可以成为学习过程的一部分。
